Recipe 리뉴얼 디자인 시안

콘셉트 이름은 ‘노른자’입니다. 회색 조리대와 흰 그릇 위에 노른자색 하나만 강조로 씁니다. 지금의 베이지·벽돌색·명조 조합보다 밝고 단순하며, 주방에서 한 손으로 보기 쉽게 글자와 버튼을 키웠습니다. 화면 구성과 흐름의 근거는 리뉴얼 기획서에 있습니다.

시간

영상 시간이 레시피의 뼈대

모든 단계에 영상 시간 칩을 붙이고, 누르면 그 시간부터 재생합니다. 재료의 근거(설명란 / 영상 1:12)도 같은 칩 모양으로 보여줍니다.

재고

냉장고가 추천을 움직인다

보유·부족·임박을 색, 아이콘, 글자로 함께 표시합니다. 색을 구분하기 어려운 사람도 ‘D-1’, ‘없음’ 같은 글자로 읽을 수 있습니다.

토큰

색, 글꼴, 부품

규칙

  • 누르는 곳은 최소 48×48px. 탭 바 아이콘은 23px, 선 굵기 1.8(선택 2.2).
  • 모서리: 칩 999px, 입력·버튼 14px, 카드 16~18px, 시트 28px. 같은 반경을 모든 블록에 쓰지 않습니다.
  • 다크 모드는 시스템 설정을 따르고, 계정 화면에서 강제로 고를 수 있게 합니다.
  • 조리 모드는 테마와 관계없이 항상 다크입니다(밤 주방의 눈부심, 배터리).
  • 색만으로 상태를 말하지 않습니다. D-day 숫자, ‘없음’, 체크 아이콘을 함께 씁니다.
  • 한국어 줄바꿈은 word-break: keep-all로 어절 단위를 지킵니다.

화면별 작업 범위

  • app.js: 탭 5개(오늘·레시피북·추가·장보기·냉장고), 추가 시트, 공유 타깃 진입 처리.
  • home.js → today.js: 분석 작업 카드(Realtime 구독), 임박 재료 추천.
  • search.js + home.js → library.js: 검색 + 필터 칩 + 보유 재료 그룹.
  • preview.js → review.js: 읽기 화면 + 확인 필요 강조 + 근거 칩 + 시청자 팁.
  • fridge.js: 실온보관 라우트를 세그먼트로 흡수, 자동입고 카드.
  • shopping.js(신규), cook.js: 미니 플레이어 자동 이동, 타이머.

Design System · v0.1

따뜻하게,
그러나 정확하게.

Recipe 앱과 기획서가 공유하는 단일 디자인 언어. Claude의 종이 같은 결을 베이스로, 머스타드·올리브의 음식 톤을 더해 식탁의 따뜻함을 표현합니다.

디자인 원칙

모든 결정이 이 다섯 가지에서 출발한다

📄

종이처럼 따뜻하게

크림 베이스와 얇은 1px 라인. 디지털 차가움 대신 노트의 결을 유지한다.

🍅

흙 톤 액센트

채도 낮은 테라코타·올리브·머스타드. 비비드 컬러는 쓰지 않는다.

✍️

세리프 헤딩

제목은 세리프로 권위와 손편지의 결을. 본문은 산세리프로 가독성.

🫁

호흡감

여백을 아끼지 않는다. 글자보다 공간이 메시지를 만든다.

🎯

장식 최소

의미 없는 일러스트·그라데이션·아이콘 잔치 금지. 콘텐츠가 먼저.

사용 규칙

합의 사항 · 충돌 시 이 페이지가 단일 출처(Single Source of Truth)

Do

  • 새로운 색상이 필요하면 먼저 기존 토큰으로 가능한지 검토
  • 제목은 항상 세리프, 본문은 산세리프
  • 한 화면에 primary CTA는 최대 1개
  • 그림자는 e-1 ~ e-3 외에 만들지 않는다
  • 아이콘이 의미를 추가하지 않으면 빼라

Don't

  • 비비드 컬러(채도 80%+) 사용 금지
  • 그라데이션 배경을 카드/버튼에 쓰지 않는다 (히어로 제외)
  • 둥근 모서리·각진 모서리 혼용 금지 (한 화면 내)
  • 이모지·아이콘을 장식 목적으로 나열 금지
  • 토큰을 무시하고 인라인 색상값 하드코딩 금지

적용 우선순위

  1. styles.css — 토큰·컴포넌트 단일 출처
  2. design-system.html — 시각적 레퍼런스 (이 페이지)
  3. plan.html — 기획서, 같은 styles.css 사용
  4. 앱 코드 — Capacitor 웹앱이 같은 styles.css import
📐
구조 — styles.css에 토큰·컴포넌트가 모두 정의되어 있고, HTML 파일들은 이를 import해 동일한 클래스를 사용한다.
